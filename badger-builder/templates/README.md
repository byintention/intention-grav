# Badger Builder templates (theme)

Section markup for Badger panels. Included as `sections/{id}.html.twig`.

| File | Panel |
| --- | --- |
| `sections/hero.html.twig` | Hero |
| `sections/features.html.twig` | Features |
| `sections/text.html.twig` | Text + image |
| `sections/full.html.twig` | Full width |
| `sections/filler.html.twig` | Filler |
| `sections/boxes.html.twig` | Boxes |
| `sections/faq.html.twig` | FAQ |
| `sections/testimonials.html.twig` | Testimonials |

Schemas: `../panels/{id}.yaml`. Page shell template stays in the plugin (`badger-builder.html.twig`).
